# 2026-09-30

## 匿名登录：URL token → 永久 token 兑换链路

需求：免登录 URL（`/#/?token=xxx`）上的 `VITE_APP_ANONYMOUS_TOKEN` 之后要经后端「匿名登录接口」换取一个**永久 token**；拿到后**会话列表 / 历史 / 删除 / 上传 / WebSocket 聊天**统一用永久 token 请求。匿名判定 = URL 是否带 `?token`；非匿名原有逻辑不动。

落地方式（不改 DifyRealDialog，兑换收在 wrapper）：
- 新增 `src/utils/anonymous-auth.ts`：
  - `resolveAnonymousAuth(urlToken)`：POST `VITE_APP_ANONYMOUS_LOGIN_URL`（body `{ token }`，带 `X-Src-System` + `token` 头），从返回体 `data.token / accessToken / permanentToken` 等字段提取永久 token；成功写 `localStorage['dify-anon-permanent-token:<urlToken>']` 缓存复用；**任何失败/未配置都优雅降级为沿用 URL token**（不抛错、不阻塞）。
  - `clearAnonymousAuthCache(urlToken)`：清缓存（暂未接线）。
- `src/views/main/index.vue`：`urlToken=getUrlAuthToken()`；`authReady=!isNoAuthAccess`；匿名时先 `resolveAnonymousAuth` 得到 `effectiveToken` 再置 `authReady=true`；`<DifyRealDialog v-if="authReady">`，`:login-account` / `:auth-token` 传 `effectiveToken`。非匿名 `authReady` 直接 true，行为不变。
- `src/typings/env.d.ts` + `viteEnv/.env{,.development,.production,.staging}`：新增 `VITE_APP_ANONYMOUS_LOGIN_URL`（**默认留空**：留空即跳过兑换、沿用 URL token，等后端接口就绪后填入实际地址）。

约定：loginAccount 与 token 在匿名态同用永久 token（原逻辑二者同为 URL token）。永久 token 缓存 key 按 URL token 维度隔离，非匿名分支永不读取。

验证：`vue-tsc --noEmit` 与 `eslint` 均通过。

待办（后端接口就绪后）：填 `VITE_APP_ANONYMOUS_LOGIN_URL`；按真实契约核对请求体/字段名（改 `pickPermanentToken` 与 body 即可）；可选：鉴权失败时清缓存重新兑换。大屏侧 datav wrapper（ai-dify-real / VAiDifyReal，9090 项目）如需同步，可直接复用本 util。
